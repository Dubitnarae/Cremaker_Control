# Cremaker Control

Cremaker Metal V2(SKR2 메인보드 + BTT TFT 화면, Marlin 2.0.8.1)를 USB로 실시간 조작하고,
프린터 화면에서 한 조작까지 감지해서 로그로 모으는 Windows 프로그램입니다. 개발자 KIM YEONGDO.

## 대상 펌웨어
메인보드 v1.2(Marlin 2.0.8.1, 2022-07-12 빌드, 기종 `Cremaker_V1.2`), 화면 v1.4(BIGTREE_TFT35_V3.0_E3.1.4) 기준.
v1.2는 챔버용 버전입니다(조명 M355·필터 팬 자동·레벨링 M101 A/B·로드 검사 변경 — v1.1 소스로 다시 만들어 bin 과 대조).
한계값·자동 보고 방식은 v1.1 소스와 같아서 그대로 씁니다. 프로그램 왼쪽 아래에 메인보드 버전이 나오고, v1.2가 아니면 주황색입니다.

## 사용법
1. 프린터를 USB로 연결하고 `Cremaker_Control.exe` 실행 → 프린터 포트를 찾아서 자동으로 연결합니다.
2. 오른쪽 버튼으로 조작합니다. '챔버 조명'은 메인보드 v1.2 에서만 됩니다. '설정 백업 · 비교'는 M503 설정을 exe 옆 `설정백업` 폴더에 저장하고 지난 백업과 다른 줄을 보여 줍니다. 아래쪽 '사건 기록' 탭에 PC 조작(검정)과 프린터 화면 조작(파랑)이 나뉘어 표시됩니다.
3. 로그는 exe 옆 `logs\날짜\` 폴더에 저장됩니다(위쪽 '로그 폴더 열기').
   - `시각_state.csv` 1초마다 온도·목표·히터 출력·위치·SD 진행·속도·유량 (엑셀로 열기)
   - `시각_events.csv` 사건 (예: 프린터 / 노즐 목표 0 → 200 °C)
   - `시각_serial.txt` 주고받은 통신 원문 전부

## 화면 조작을 어떻게 아는가
메인보드에서 화면(TFT)과 USB는 서로 다른 통신 포트라서(Configuration.h `SERIAL_PORT 1`, `SERIAL_PORT_2 -1`)
화면에서 누른 명령 자체는 USB로 오지 않습니다. 대신 온도·위치·SD 자동 보고는 두 포트에 다 오므로
(libs/autoreport.h `report_port_mask = All`) 값이 바뀌면 사건으로 남깁니다. PC가 5초 안에 같은 종류의 명령을 보냈으면 'PC', 아니면 '프린터'입니다.
속도·유량은 자동 보고가 없어 5초마다 M220·M221 로 물어봅니다.
**알 수 없는 것:** 팬 속도 변경, 메뉴를 열기만 한 것처럼 값이 안 바뀌는 조작.

## 화면에서 시작한 출력의 진행 상황
화면(TFT)이 자기 SD·USB 파일을 메인보드로 흘려보내는 출력은 메인보드가 파일을 몰라 진행률이 USB로 오지 않습니다.
그래서 위치 자동 보고로 경과 시간·출력 높이(XY 이동하며 압출할 때의 Z)·층 바뀐 횟수·압출 길이를 셉니다.
같은 G코드 파일을 '출력 파일 맞추기'로 열면 Cura 주석(`;TIME:` `;LAYER:` `;TIME_ELAPSED:`)과 층별 Z로
진행률·남은 시간을 계산합니다(층 단위, 남은 시간은 지금까지의 실제/예상 속도 비로 고침). 출력이 60초 넘게 멈추면 끝으로 봅니다.

화면 펌웨어를 직접 만든 v1.5 이상으로 바꾸면 화면이 진행률을 USB 로 알려 줍니다
(`TFT_PROGRESS P<%> T<경과 초> C<읽은 바이트> S<파일 바이트> H<일시정지>`, 메인보드가 `M118 P2` 로 USB 에만 내보냄).
이때는 '출력 진행'에 화면이 잰 진행률(0.1 %)·경과·남은 시간이 나오고, 맞춘 G코드 파일이 있으면 층과 파일 크기 일치 여부도 함께 보입니다.

## 도구 메뉴 · 출력 기록 (v0.2.0)

- **알림**: 출력 끝·일시정지·오류·온도 이상·출력 중 연결 끊김을 Windows 알림으로 띄웁니다. 도구 → 알림 설정에서 텔레그램 봇 토큰과 채팅 ID 를 넣으면 텔레그램으로도 보냅니다 (값은 exe 옆 `설정.ini`).
- **출력 기록**: 출력이 끝날 때마다 exe 옆 `출력기록.csv` 에 시작·끝·걸린 시간·파일·예상 대비·필라멘트 g·비용을 한 줄씩 남깁니다. 아래 '출력 기록' 탭에서 결과·메모를 고칠 수 있습니다. 3분보다 짧은 움직임(손 압출 등)은 기록하지 않습니다.
- **온도 이상 경고**: 목표에 한 번 닿은 뒤 노즐이 ±5 °C 를 10초, 베드가 ±3 °C 를 30초 넘게 벗어나면 경고합니다.
- **노즐 PID 자동 조정**: 팬을 켠 채 `M303 E0 S<온도> C8 U1` 을 돌리고 예전·새 값을 비교해 보여 준 뒤 저장(M500)할지 묻습니다.
- **드라이버 · 원점 점검**: X·Y 60 mm, Z 10 mm 를 왕복하며 `M122` 의 드라이버 통신과 sg_result(막힘 감지 신호)를 읽습니다. 움직여도 0 만 나오면 모듈 고장 의심, Z 가 200 아래면 Z 원점이 실패할 수 있다고 알려 줍니다.

## 안전 한계 (펌웨어 값)
축 X -8~220, Y -6~220, Z 0~260 (펌웨어 소프트 리밋이 막음), 노즐 260 °C, 베드 90 °C, 압출은 170 °C 이상.
펌웨어의 ABS 예열 베드 110 °C 는 베드 한계를 넘어서 240/90 으로 씁니다.
출력 중으로 보이면(SD 출력 또는 가열 중 압출이 계속됨) 이동·홈·압출 버튼을 잠급니다.
